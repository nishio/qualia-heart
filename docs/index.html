LLM を使わない辞書型対話 — 現代の Heart

これは何？

このクオリアさんは、実行時に LLM を一切使いません。大型の LLM があらかじめ書いた会話ルール （ユーザー発話の例文と返答）をブラウザが読み込み、入力と例文の文字 n-gram の近さで返答を選びます。 1999〜2004 年の人工無脳「Heart」と同じく、人格データと再生エンジンが分かれています。

「仕組み」をオンにすると、どのルールが選ばれたかと候補の得点が見えます。
