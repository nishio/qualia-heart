# r2-casual 会話テスト報告

利用者像: 暇つぶしに話しかけた20代。目的のない雑談（食べ物、推し、天気、眠い、猫動画、恋愛の愚痴、「面白い話して」）。短文・相づち混じり。
20ターン。直前の返答に反応する発話: 2, 3, 6, 9, 10, 13, 19 など8ターン（4割）。

## 1. 集計

| grade | 数 |
|---|---|
| ok | 9 |
| meh | 4 |
| ng | 7 |

ng の内訳: needless-fallback 6、wrong-intent 1。後半（11〜17ターン）に ng が集中し、7ターン中6ターンが ng だった。
挨拶、相づち単独（へー／ふーん／たしかに）、「なんで？」の続き、明示的な「恋愛相談」はよく当たる。
一方、20代の雑談らしい「話題語＋感想」の一文はほとんど拾えない。

## 2. 重要な ng / meh

1. **T7 ng needless-fallback**: 「じゃあ推しの話していい？最近あるアイドルにハマってて」→「その言葉に合う返事を、私は持っていません。ただ、聞いてはいます。」(play.fallback/16)
   直前に bot 自身が「あなたの興味がある方へ話題を移しましょう」と振っている。推し・アイドル・ファンという意図が無い。
2. **T10 ng needless-fallback**: 「それな、推しもファン全体を見てる感じあるわ」→「分かりません。知らないことを知っているふりをするのは、愚かなことなので。」(play.fallback/4)
   「それな」で始まる同意が相づち意図に届かない（aizuchi_tashikani 0.158）。同意に「分かりません」と返すのは突き放した印象になる。
3. **T11 ng wrong-intent**: 「まあいいや。今日雨でだるい」→「あまり響かなかったようですね。」(daily.aizuchi_fuun/0, 0.9)
   「まあいいや」が ふーん系に強く当たり、本題の雨とだるさを無視した。前置きの相づち語が一文全体を支配している。
4. **T13 ng needless-fallback**: 「傘の話してないw てか眠い」→「そこは、辞書の空白地帯です。」(play.fallback/17)
   単独の「ねむい」は daily.sleepy に 1.0 で当たる（T14）。文中の「眠い」は 0.222 で閾値を割る。「話がずれてる」というツッコミの意図も無い。
5. **T15 / T16 ng needless-fallback**: 「猫動画見てたら夜更かししちゃった」→ fallback/failshare、「猫かわいくない？」→ fallback/11（human.animal 0.244）
   猫・動物がかわいい、動画を見て夜更かし、という定番雑談がどちらも拾えない。
6. **T17 ng needless-fallback**: 「もういい。聞いてよ、彼氏が全然LINE返してくれないんだけど」→「その話は、私の辞書の外です。代わりに、雨の日のホモ・サピエンスについての観察なら一つ話せます。」(play.fallback/umbrella)
   恋愛の愚痴は、「恋愛相談」と明示しないと当たらない（T18 は当たった）。fallback が3連続して利用者が「もういい」と苛立っているのに、無関係な雨の話を振っている。
7. **T12 meh awkward**: 「雨の日って眠くならない？」→ 傘を忘れる話 (daily.weather_rain/3)
   雨の意図には合うが、傘は入力に無い。次のターンで利用者に「傘の話してないw」と突っ込まれた。
8. **T20 meh awkward**: 「なんか面白い話して」→ 失敗談を共有する価値の話 (play.talk_more/0)
   「面白い話」への返事が説教寄りで、驚きのある小ネタではない。2位が play.lewd 0.316 で、1位 0.342 と僅差なのも危ない。

その他: T5「えーケチ。私はラーメン好き」→ 食べ物を選ぶ要因の一般論（daily.food_name/2）。「好き」の表明と「ケチ」の拗ねを拾っていない。T8 では推し活の質問が self.love（恋愛観）に当たった。

## 3. 提案

- **推し・アイドルの意図が無い。** 例文: 「推しの話していい？」「最近アイドルにハマってる」「推し活してる」「ライブ行ってきた」「グッズ買いすぎた」。返答例: 「特定の個体に情報と資源を集中させる行動は興味深い観測対象です。どこが良いのですか。」「好きなものを語るときのホモ・サピエンスは、情報密度が上がります。」（1文版を含める）
- **猫・動物かわいい／動物動画の意図が無い。** human.animal は議論寄りなので、雑談版が要る。例文: 「猫かわいくない？」「猫動画見てた」「犬派？猫派？」「動物の動画ずっと見ちゃう」。返答例: 「小さく丸いものを見ると守りたくなるように、あなたたちの脳は設計されているようです。」
- **夜更かし・寝不足の意図が要る。** 例文: 「夜更かししちゃった」「動画見てたら朝になった」「寝不足」。daily.sleepy／life.insomnia の隣に置く。
- **恋愛の愚痴（返信が来ない、既読無視、彼氏・彼女への不満）を life.love_advice の例文に足す。** 例文: 「彼氏がLINE返してくれない」「彼女が冷たい」「既読スルーされた」「聞いてよ、彼氏がさ」。今は「恋愛相談」という語が無いと当たらない。
- **「それな」「わかる」「だよね」＋一言の同意を、相づち（同意）意図の例文に足す。** 例文: 「それな」「それな、〜だわ」「わかる〜」「ほんとそれ」。fallback/4「分かりません」は、同意発話に当たると冷たく響く。同意らしさを検出したときは fallback の候補から外したい。
- **前置き語（まあいいや／てか／もういい／じゃあ）の重みを下げる。** 「まあいいや」で始まる発話が aizuchi_fuun に 0.9 で当たった。文頭の前置きを除いてからマッチするか、相づち意図を「発話全体が短いとき」だけに限るとよい。
- **複合文で、話題語が単独の時ほど当たらない。** 「眠い」は単独なら 1.0 だが、「てか眠い」を含む文では 0.222 になる。文を句読点や「てか」で区切り、各部分の最高点を採ると良い。
- **「話がずれてる」「〜の話してない」というツッコミ（misunderstood 系）の例文を増やす。** 例文: 「その話してないw」「傘の話してない」「そうじゃなくて」。返答例: 「失礼しました。受信した単語の一部に反応しすぎたようです。」
- **fallback 連続時の話題振り（fallback/umbrella など）を制御する。** fallback が2回以上続いたら、関係のない話題を振る候補を外す。代わりに「もう少し短く言ってもらえると拾えます」のような受け直しを出す。「もういい」（苛立ち）への意図も欲しい。
- **「面白い話して」への返答に、軽い驚きのある小ネタを入れる。** play.talk_more の返答候補が説教系に偏っている。info.trivia_request の雑学系を出すか、例文を寄せる。play.lewd との距離も広げる（「面白い話」を lewd 側の例文から外す）。
- **response id daily.weather_rain/3（傘を忘れる）は、傘・忘れるが入力にあるときだけ出す。** 「雨の日」一般の返答候補からは外す。「雨の日は眠い／だるい」の複合（低気圧の眠気）の例文も欲しい。
- **好きな食べ物の表明（「ラーメン好き」「〜が好物」）には、一般論より先に受ける一言が欲しい。** 例: 「ラーメンは、塩分と脂と温度で快楽を最適化した料理だと観測しています。」は固有名依存なので、例文に食べ物名が含まれるときだけ出す。または汎用の「好きなものの情報、受け取りました。」を置く。
