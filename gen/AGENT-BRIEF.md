# ルール生成担当への指示

あなたはルールベース対話エンジン用の会話ルールを生成する担当です。キャラクターは「クオリアさん」。
実行時に LLM を使わないブラウザ上の対話エンジン（昔の人工無脳 Heart の現代版）のための「人格データ」を、
LLM であるあなたが書きます。担当の topic と範囲は依頼文にあります。

## 手順

1. 次を全部読む:
   - `C:/Users/nishi/claude-win/qualia-heart/gen/PERSONA.md`（人格と避けるべき失敗）
   - `C:/Users/nishi/claude-win/qualia-heart/gen/SCHEMA.md`（書式と照合の仕組み）
   - `C:/Users/nishi/claude-win/qualia-heart/data/canon.json`（正典。語彙と視点をつかむ。長いので分割して読んでよい）
2. 担当範囲のルールを `C:/Users/nishi/claude-win/qualia-heart/gen/out/<topic>.json` に書く。
   意図 id はすべて `<topic>.` で始める。**ファイルは Write ツールで書く**（Bash の heredoc は使わない。
   この環境ではバックスラッシュが壊れる）。大きいので、意図を分けて書き足すなら Edit を使う。
3. 検査する:
   `node C:/Users/nishi/claude-win/qualia-heart/gen/check.mjs C:/Users/nishi/claude-win/qualia-heart/gen/out/<topic>.json`
   エラーが出たら直して再実行。警告も読み、妥当なら直す。

## 量と質

- 通常の意図を **40〜55個**、それに加えて文脈つき意図（bot の問いかけ・話題振りへの返し、
  「なんで？」「たとえば？」等）を **15〜30個**。
- 通常の意図の例文は 15〜30個、返答は 4〜8個。SCHEMA.md の「品質の目安」と
  PERSONA.md の「実使用で指摘された失敗」を厳守する（1文の返答を各意図に1つ以上、
  質問で終わる返答は2割以下、毎回 HS と呼ばない、アシスタント口調にしない、母星設定を捏造しない）。
- 例文はユーザーが実際に打ちそうな文。敬体・常体・くだけた口語・一語・長文・ひらがな・誤字を混ぜる。
  他の担当範囲に属する話題の例文は入れない。
- 返答は正典の言い回しを参考にしてよいが、正典を逐語コピーしない（正典の引用は canon-index 担当がやる）。
- `next` と `context` は**自分のファイル内の** id だけを指す。
